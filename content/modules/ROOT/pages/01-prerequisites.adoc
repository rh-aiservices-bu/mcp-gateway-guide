= Phase 1: Prerequisites

Install the {mcp-gw} operator via OLM on {ocp-short}.

TIP: All file paths and `oc apply` commands in this guide are relative to the link:{repo-url}[mcp-gateway-guide] repository root.

IMPORTANT: This guide is not a replacement for the link:https://docs.redhat.com/en/documentation/red_hat_connectivity_link/1.4/html/install_the_mcp_gateway/mcp-gateway-install[official {rhcl} {mcp-gw} documentation].

== Overview

The {mcp-gw} is delivered as an operator through the Red Hat Operator catalog. The operator manages the MCP Gateway controller and broker components that handle MCP server registration, tool aggregation, and request routing.

[cols="1,1,3", options="header"]
|===
| Component | Namespace | Purpose

| MCP Gateway Operator
| `mcp-gateway`
| Manages MCPGatewayExtension, MCPServerRegistration, and MCPVirtualServer CRDs

| MCP Gateway Controller
| `mcp-gateway`
| Watches CRDs and configures the Gateway and HTTPRoutes

| MCP Gateway Broker
| `mcp-gateway`
| Handles MCP protocol sessions, tool aggregation, and request routing
|===

== Installation

=== Step 1: Create the Namespace

[source,bash]
----
oc apply -f manifests/01-prerequisites/operators/namespace.yaml
----

=== Step 2: Install the MCP Gateway Operator

[source,bash]
----
oc apply -k manifests/01-prerequisites/operators/
----

This creates the OperatorGroup and Subscription for the `mcp-gateway` operator from the `redhat-operators` catalog source.

== Verification

=== Wait for Operator CSV to Succeed

[source,bash]
----
oc wait csv -n mcp-gateway \
  -l operators.coreos.com/mcp-gateway.mcp-gateway="" \
  --for=jsonpath='{.status.phase}'=Succeeded --timeout=600s
----

TIP: Operator CSVs take 30-60 seconds to appear after applying subscriptions. If `oc wait` returns "no matching resources found", wait a minute and retry.

=== Verify CRDs Are Available

[source,bash]
----
oc get crd mcpgatewayextensions.mcp.kuadrant.io
oc get crd mcpserverregistrations.mcp.kuadrant.io
oc get crd mcpvirtualservers.mcp.kuadrant.io
----

=== Check Operator Pods

[source,bash]
----
oc get pods -n mcp-gateway
----

You should see the MCP Gateway controller and broker pods running.

=== Quick Status Check

[source,bash]
----
oc get subscriptions.operators.coreos.com -n mcp-gateway \
  -o custom-columns='NAME:.metadata.name,CSV:.status.currentCSV,STATE:.status.state'
----
