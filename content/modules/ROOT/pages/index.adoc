= MCP Gateway on OpenShift Guide

Guide to deploy and configure {mcp-gw} ({rhcl} 1.4) on {ocp-short}.

* Kustomize manifests with status gates between every phase
* Single automation script for end-to-end deployment
* Real authentication and authorization examples with Keycloak
* Two MCP servers (test, risk assessment) for hands-on validation

Requires OpenShift 4.19+ with cluster-admin access.

WARNING: {mcp-gw} is a Technology Preview feature in {rhcl} 1.4. Technology Preview features are not supported with Red Hat production service level agreements (SLAs) and might not be functionally complete.

IMPORTANT: This guide is not a replacement for the link:https://docs.redhat.com/en/documentation/red_hat_connectivity_link/1.4/html/install_the_mcp_gateway/mcp-gateway-install[official {rhcl} {mcp-gw} documentation]. It is a companion resource with opinionated Kustomize manifests and automation scripts to accelerate deployment.

== What is MCP Gateway?

The Model Context Protocol (MCP) Gateway provides enterprise-grade governance and security for AI agent traffic. It acts as a centralized control plane between AI agents and MCP servers, adding:

* *Aggregation* - Combine multiple MCP servers behind a single endpoint
* *Authentication* - OAuth 2.1 resource server with JWT validation
* *Authorization* - Tool-level access control using CEL expressions
* *Virtual Servers* - Curated tool collections for specific use cases

== Getting Started

Clone the repository and work from its root directory. All commands and file paths in this guide are relative to the cloned repo.

[source,bash,subs="+attributes"]
----
git clone {repo-url}.git
cd mcp-gateway-guide
----

You also need:

* {ocp-short} 4.19+ cluster with `oc` CLI authenticated as cluster-admin
* `envsubst`, `curl`, `jq` available on PATH

== Key Custom Resources

[cols="1,1,2", options="header"]
|===
| CRD | API Group | Purpose

| `MCPGatewayExtension`
| `mcp.kuadrant.io/v1alpha1`
| Connects the MCP Gateway to a Gateway listener

| `MCPServerRegistration`
| `mcp.kuadrant.io/v1alpha1`
| Registers an MCP server with the gateway via HTTPRoute

| `MCPVirtualServer`
| `mcp.kuadrant.io/v1alpha1`
| Creates curated tool collections from registered servers
|===
