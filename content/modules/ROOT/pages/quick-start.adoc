= Automated Setup

Deploy {mcp-gw} on {ocp-short} using a single automation script.

NOTE: The script follows *Track A* from xref:01-prerequisites.adoc[Phase 1] - it installs OpenShift Service Mesh 3 and creates an Istio control plane. If your cluster already provides a GatewayClass (for example an Ingress-Operator-managed Istio), do not use this script as-is: it will create a conflicting second control plane. Follow the phases manually instead.

The script defaults to `GATEWAY_CLASS=istio` and `GATEWAY_NAMESPACE=mcp-gateway`, and both are read from the environment. If you are reusing an existing provider and skipping phase 1, set them before running it:

[source,bash]
----
export GATEWAY_CLASS="openshift-default"
export GATEWAY_NAMESPACE="mcp-gateway"
./scripts/setup-mcp-gateway.sh --from-phase 2
----

IMPORTANT: The script does not set `privateHost` on the `MCPGatewayExtension`. On any GatewayClass other than `istio` you must set it yourself after phase 3, or `tools/call` fails while everything else reports healthy - see xref:03-mcp-gateway-extension.adoc#privatehost[Setting privateHost].

== Basic Installation (Phases 1-5)

Installs the MCP Gateway operator, configures the Gateway, deploys two in-cluster MCP servers plus one external server, and verifies tool discovery.

[source,bash]
----
./scripts/setup-mcp-gateway.sh
----

== Full Installation with Auth (Phases 1-9)

Adds {rhbk}, authentication, authorization, and virtual MCP server configuration.

[source,bash]
----
./scripts/setup-mcp-gateway.sh --with-auth
----

== Script Options

[cols="1,2", options="header"]
|===
| Flag | Description

| `--with-auth`
| Include phases 6-9 ({rhbk} realm, authentication, authorization, virtual servers)

| `--from-phase N`
| Resume from phase N (skips completed phases)

| `--namespace NS`
| Override the MCP gateway namespace (default: `mcp-gateway`)

| `--dry-run`
| Print commands without executing them
|===

== Verification

After the script completes, run the verification script:

[source,bash]
----
./scripts/verify.sh
----

This performs MCP session initialization and tool discovery, verifying that all registered MCP servers respond correctly through the gateway. It detects automatically whether an AuthPolicy is in force and fetches a token when needed; override with `--with-auth` or `--no-auth`.

== Teardown

To remove all resources created by the guide:

[source,bash]
----
./scripts/teardown.sh
----
